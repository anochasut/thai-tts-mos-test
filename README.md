# Thai TTS MOS Listening Test

A blind listening test: participants sign in with Google, hear one practice clip (see
`demo_audio/` + `demo_meta.json`, not scored), then rate every clip in `manifest.csv`
for naturalness/intelligibility (1-5, ITU-T P.800 style) and transcribe what they
heard. System identity is hidden behind opaque tokens (see `manifest.csv`); the real
mapping is kept outside this repo. English and Thai instructions are shown together
throughout.

Sign-in is Streamlit's built-in OIDC (`st.login`), configured under `[auth]` in the
app's secrets -- see `../SETUP.md` step 4b. With no `[auth]` section the app falls back
to a local/dev mode that just asks for an email address; don't run a real study that
way. Sign-in is what makes three things possible:

- **Resuming.** Each answer is uploaded as it's given, along with the participant's
  clip order, so they can stop any time and sign back in to continue where they left
  off -- same order, first unanswered clip.
- **Editing.** Previous / Review pages let them revisit any clip and change their
  answer; the re-saved file overwrites the original (flagged `"edited": true`).
- **Monitoring.** Emails listed in the `ADMIN_EMAILS` secret get a
  "Monitor participants" dashboard showing everyone's progress live.

Results go to a private Hugging Face **dataset** repo (`RESULTS_REPO_ID` + `HF_TOKEN`
secrets), laid out as:

```
{manifest_id}/{session_id}/_session.json          participant info + their clip order
{manifest_id}/{session_id}/{index:03d}_{utt}.json one file per answered clip
```

`manifest_id` is a hash of `manifest.csv`, so every regeneration of the test set gets
its own folder -- rounds never mix, and nobody can resume into a set that changed
underneath them. `session_id` is derived from the participant's email.

Secrets: see `.streamlit/secrets.toml.example` for the full template. The real
`.streamlit/secrets.toml` is gitignored -- never commit it.

`manifest.csv`, `audio/`, `demo_audio/`, and `demo_meta.json` are all generated by
`../prepare_manifest.py` -- don't hand-edit them; re-run that script instead (see
`../SETUP.md`, section 0) whenever the dataset or the included-utterance list changes.

Deployed on Streamlit Community Cloud. See `../SETUP.md` (in the parent project
folder) for deployment steps and `../analyze_results.py` for scoring (MOS + WER/CER
against ground truth).
